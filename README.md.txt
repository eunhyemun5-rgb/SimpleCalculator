- 화면구성:   - 숫자 입력: 텍스트 박스 또는 버튼

## 실행화면
-과제1 실행화면
- 과제 내용 
label1, textbox, button를 적절히 배치합니다.
컨트롤 배치와 기본적인 속성 설정
계산기의 더하기 기능 구현
-구현 내용과 기능설명
0부터 9까지의 버튼을 눌러 원하는 숫자를 연속해서 입력할 수 있습니다.
숫자+숫자를 치고선 =버튼을 누르면 결과값이 나옵니다.
처음엔 0+0=00 이런식으로 나와 당황하였지만 제미나이와 코파일의 도움으로 해결하였습니다.
## 과제 2 실행화면

-구현 내용과 기능설명
더하기(+)뿐만 아니라 빼기(-), 곱하기(X), 나누기(÷) 버튼을 눌러 모든 기본 산술 연산을 수행할 수 있습니다.
+ 버튼과 완벽히 동일한 로직을 사용하되, currentOperator 변수에 들어가는 문자열 값만 "-", "*', "/"로 다르게 저장하여 코드의 중복을 최소화했습니다.

##-과제 3 실행

-구현 내용과 기능설명
c:계산 도중 완전히 새로운 계산을 처음부터 다시 시작하고 싶을 때 사용합니다.
